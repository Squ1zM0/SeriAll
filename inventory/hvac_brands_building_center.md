# Building Center HVAC brand inventory (SeriAll Phase 1)

Source: Building Intelligence Center (building-center.org) HVAC index
(https://www.building-center.org/hvac-table-of-contents-2/).
Enumerated Oct 28, 2026 via the site's public WordPress REST pages
endpoint (search `hvac age`, pages 1–6), filtered to slugs ending in
`-hvac-age`. Brand names below are derived from slugs for readability;
the URL is the authority. No Building Center prose is copied here —
brand names + page URLs + family groupings only (facts).

## Count: 417 HVAC brand pages

Method caveat: the REST search is relevance-ranked, so a small number
of brand pages could be missed if they rank beyond page 6 or do not
match the search terms. Phase 2 should re-verify this list against the
index dropdowns before treating it as exhaustive. Known near-misses
NOT in this list (different page types, flagged for Phase 2 checks):
Gree (brand page without an `-hvac-age` slug), Midea, and the separate
Water Heater Index (v2 scope, not inventoried here).
